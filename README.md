# ПВЗ — график сотрудников + Дашборд ЗП

Сайт управления графиком сотрудников ПВЗ, чекинами, расчётом зарплаты
и автоматическими звонками при пропуске смены.

## Структура

- `index.html`, `css/`, `js/`, `manifest.json`, `icons/` — сам сайт
  (это то, что нужно GitHub Pages для работы сайта)
- `supabase/functions/` — серверные функции (деплоятся отдельно, напрямую
  через Supabase Dashboard, не через этот репозиторий)
- `supabase_*.sql` — справочные SQL-скрипты структуры таблиц Supabase
  (уже выполнены, оставлены для истории/восстановления)

## Технологии

Чистый JavaScript + Supabase (без сборщиков и фреймворков).
