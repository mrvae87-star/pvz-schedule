# 🏪 PVZ Manager New

Система управления графиком сотрудников пунктов выдачи заказов.

## 🚀 Возможности

- 👥 Управление сотрудниками (CRUD)
- 📅 Создание графиков работы по ПВЗ
- 💰 Расчёт зарплаты с учётом подработок и штрафов
- 📊 Аналитика рабочих дней
- ✅ Чекин сотрудников на смену
- 🆘 Экстренные контакты
